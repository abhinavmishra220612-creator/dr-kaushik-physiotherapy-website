DR. KAUSHIK'S PHYSIOTHERAPY CLINIC
=================================

Files
-----
index.html   - Main website page
style.css    - Website styling and responsive layout
script.js    - Mobile menu and small interactions

How to use
----------
Keep all 3 files in the same folder.

For GitHub Pages:
1. Create/open repository: dr-kaushik-physiotherapy
2. Upload index.html, style.css and script.js.
3. Commit the changes to the main branch.
4. Go to Settings -> Pages.
5. Under Build and deployment choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)".
7. Save.
8. GitHub will provide the Pages URL.
